&#x20;Анализ атомарности атрибутов



\## 1. Сущность: Products (Товары)



\### Список атрибутов:

1\. product\_id

2\. product\_name

3\. price

4\. category\_id

5\. class

6\. modify\_timestamp

7\. resistant

8\. is\_allergic



\### Анализ атомарности:



| Атрибут | Атомарен? | Обоснование |

|---------|-----------|-------------|

| product\_id | Да | Числовой идентификатор, одно значение на товар |

| product\_name | Да | Одно название товара в виде строки |

| price | Да | Числовое значение (цена), десятичная дробь |

| category\_id | Да | Числовой идентификатор категории, ссылка на другую таблицу |

| class | Да | Одиночный символ (A, B или C) |

| modify\_timestamp | Да | Одна дата и время в едином формате |

| resistant | Да | Булево значение (Yes/No) |

| is\_allergic | Да | Булево значение (Yes/No) |



Вывод: все атрибуты атомарны, так как каждая ячейка содержит ровно одно неделимое значение.

\## 2. Сущность: Employees (Сотрудники)



\### Список атрибутов:

1\. employee\_id

2\. first\_name

3\. middle\_initial

4\. last\_name

5\. birth\_date

6\. gender



\### Анализ атомарности:



| Атрибут | Атомарен? | Обоснование |

|---------|-----------|-------------|

| employee\_id | Да | Числовой идентификатор, одно значение |

| first\_name | Да | Одно имя в виде строки |

| middle\_initial | Да | Одна буква (инициал отчества) |

| last\_name | Да | Одна фамилия в виде строки |

| birth\_date | Да | Одна дата в формате YYYY-MM-DD |

| gender | Да | Одна буква (F или M) |



Вывод: все атрибуты атомарны, так как каждая ячейка содержит ровно одно неделимое значение.
